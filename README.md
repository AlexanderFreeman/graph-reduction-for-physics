# Computational Graph Reduction for Physics Simulations

Research software and reproducibility materials for accelerating physics simulations with physics-informed machine learning and computational graph reduction.

## Repository layout

```text
studies/
  local-grid-coarsening/
    README.md
    code/
    experiments/

.....
```

Each study has its own README with the problem setup and code for reproducing its results.
